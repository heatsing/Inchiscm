# SEO 90-Day Targets

This document records recovery goals for inchiscm.com. It is not permission to mass publish pages.

## Recovery Batch 1 focus

Primary objective: recover the previously tested height-conversion cluster without adding new URLs.

Modified URLs:

- `/height-converter/`
- `/6-11-in-cm/`
- `/4-7-in-cm/`
- `/6-8-in-cm/`
- `/4-10-in-cm/`
- `/6-4-in-cm/`
- `/6-10-in-cm/`

## Baseline supplied for this batch

- Total clicks: 4
- Total impressions: 43,430
- Average position: 20.91
- Height pages: 29,932 impressions
- Latest 7-day impressions: 139
- Latest weighted average position: approximately 75.73
- Mobile: 25,102 impressions, average position 9.68
- Desktop: 18,033 impressions, average position 36.82

## 90-day targets

- Regain stable impressions on the six recovery height pages.
- Improve CTR by making titles, direct answers, formula steps, and notation clarification match search intent.
- Keep all existing URLs live, indexable, self-canonical, and included in the sitemap.
- Avoid new page creation until GSC shows repeated query gaps that existing pages cannot satisfy.
- Keep AdSense paused until organic traffic is stable and the converter experience remains clean.

## Measurement rules

- Review 7-day top queries and top pages before each recovery decision.
- Segment by device because mobile and desktop showed different ranking behavior.
- Do not overreact to single-day changes.
- Treat decimal-height variants as notation problems to clarify on existing pages, not as new URL opportunities.
